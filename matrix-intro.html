Unfortunately, no one can be told what the Matrix is. You have to see it for yourself.

안타깝게도 누구도 매트릭스가 무엇인지 말해줄 수 없다. 직접 봐야 한다.

The Matrix(1999)는 워쇼스키 자매 감독의 SF 액션 영화로, 인류가 거대한 시뮬레이션 속에서 살아간다는 설정에서 출발한다. 네오는 «진실»을 제안하는 모피어우스를 만나고, 빨간 알약을 택하면 가짜 평온 뒤에 숨은 현실로 들어선다.

Core Theme
현실 / 통제 / 자유의지 / 선택
Narrative Tone
사이버펑크 / 무술 액션 / 철학적 질문

시즌 1~3은 작품 속 흐름을 따라 각성·저항·균형으로 이어진다.

Season 1
현실 / 각성 / 선택 / 진실
Season 2~3
저항 / 운명 / 희생 / 새로운 질서

인류와 기계의 전쟁, 매트릭스 설계, 더 원의 순환, 시온의 반복이 세계관의 뼈대를 이룬다.

Origin
B166ER 사건 이후 제로원 독립, 전쟁, 인류 패배
System Cycle
오라클·아키텍트 구조, 더 원의 등장, 시온 파괴/재건 반복
Neo Breakpoint
트리니티를 선택해 기존 질서를 깨뜨리고 스미스 사태를 종결
Aftermath
잠시의 평화 이후 다시 흔들리는 균형, 이어지는 확장 서사
